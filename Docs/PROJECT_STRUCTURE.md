# Restaurant Telegram Mini App --- Project Structure

This document gives a short overview of the current project structure
and the responsibility of its main folders and files.

## Main Structure

``` text
restaurant-telegram-mini-app/
├── data/
├── Docs/
├── node_modules/
├── server/
├── src/
├── .env
├── .env.example
├── .gitignore
├── index.html
├── metadata.json
├── package-lock.json
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## Frontend --- `src/`

The `src/` folder contains the React and TypeScript frontend shown to
the restaurant customer.

``` text
src/
├── components/       Reusable UI components
├── data/             Restaurant/menu data used by the UI
├── views/            Main application screens/pages
├── App.tsx           Main React application component
├── index.css         Global styles
├── main.tsx          React application entry point
└── types.ts          Shared TypeScript types
```

The frontend displays the restaurant, menu, contact information and
booking interface, and sends reservation requests to the backend API.

## Backend --- `server/`

The `server/` folder contains the Node.js/Express backend.

``` text
server/
├── database.ts       SQLite database setup and access
├── email.ts          Nodemailer/SMTP email service
└── index.ts          Express API and backend entry point
```

The backend validates reservations, generates reservation references,
stores reservations in SQLite, and sends confirmation emails.

## Data and Database --- `data/`

``` text
data/
├── restaurant.db
├── restaurant.db-shm
└── restaurant.db-wal
```

`restaurant.db` is the SQLite database. The `-shm` and `-wal` files are
SQLite working files created while the database is running.

## Libraries --- `node_modules/`

`node_modules/` contains installed npm packages such as React, Express,
Nodemailer, Vite, dotenv and better-sqlite3.

This folder is generated by npm and should not be edited manually or
committed to Git.

## Documentation --- `Docs/`

The `Docs/` folder contains project documentation, including
architecture and implementation notes.

## Important Root Files

-   `.env` --- real local configuration and secrets; never commit it.
-   `.env.example` --- safe template showing required environment
    variables.
-   `.gitignore` --- tells Git which local/generated files to ignore.
-   `package.json` --- project scripts and npm dependencies.
-   `package-lock.json` --- locks installed dependency versions.
-   `index.html` --- HTML entry page used by Vite.
-   `tsconfig.json` --- TypeScript configuration.
-   `vite.config.ts` --- Vite configuration and development API proxy.
-   `metadata.json` --- project/application metadata.

## Architecture at a Glance

``` text
React frontend (`src/`)
        ↓
Express API (`server/index.ts`)
      ↙       ↘
 SQLite       Email
 database    Nodemailer
```

The project is therefore divided into a **React frontend**, a
**Node.js/Express backend**, and supporting **libraries, data,
configuration and documentation**.
